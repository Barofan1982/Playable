# Juicy Journey · 洗衣房寻物

参考：Tasty Travels_ Merge Game-360 X 640-2026-10-02-00d726c57964795e7e61949f80b0848b.mp4，360 × 640，30.016 秒。

双击 index.html 可离线运行。当前版本为独立寻物试玩，图片、商标与脚本全部内嵌。

## 操作与结尾

- 在 Sera 的洗衣房寻找袜子、蓝色壶、纸巾盒、橙色洗衣液和圆形镜子，每类 2 件，共 10 件。
- 点击实际可见的物品轮廓收集。物品飞到顶部清单后，对应圆点变为勾，总数才增加。
- 每件只能收集一次。错点显示叉号；拖动、取消触控和重复点击不会重复收集。
- HINT 用金色圆环标出一件尚未找到的物品。
- AUTO PLAY 每秒找一件，再点可停止；手动点击目标也会接管。
- 十件全部飞入清单后显示 Good Job!，完成动画后持续保持最后画面。
- 完成后提示与自动按钮停用，只有手动点击 RETRY 才重新开始。
- 声音默认关闭，可手动打开。

## 物品摆放修订（2026-10-02）

- 按背景原图的架板、长凳、台面、篮沿和地面定位，底部与承托面接触点对齐，阴影跟随落点。
- 统一只使用图集第一排的五类道具，每类独立放置两件，保持同一视角与原始宽高比。
- 两只袜子分别搭在左右篮沿；水壶贴合长凳与水槽上沿；架下镜子收进承托面范围内；纸巾盒和前景道具调整位置与尺度。
- 保持物品原始宽高比，使用较细描边与柔和高光。
- 前景纸巾盒部分被篮沿和衣物遮住，遮住的部分不能收集。
