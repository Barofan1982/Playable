# 视觉与素材说明

本关按用户提供的第二条 Color Block Builder 视频重绘。视频仅用于参考，没有截取视频帧充当游戏画面，也没有引用第三方角色或品牌素材。

- 淡灰白格纹背景、白色目标图框、木色台面、凹槽和彩块全部由 Canvas 在本地绘制。
- 拼图为九色多格积木与白色 L 形间隔块。待释放状态使用半透明粉彩色，释放后使用参考对应的饱和木色与细木纹。
- 目标图复用同一块形数据按比例绘制，不是静态截图。
- 失败大红叉与成功提示由 Canvas 绘制；没有角色。
- Matter.js 0.20.0（MIT）负责实际的重力、接触、摩擦和刚体旋转。多格块先合并连续矩形，再刚性复合，使用细小木块倒角；未释放块不参与动态碰撞。自动释放与手动点击使用相同碰撞模型。
- 音效由 Web Audio 在用户操作后合成，只有短释放、碰撞、失败与成功音，没有音乐。音效上下文注册到内嵌的 effects-only helper；页面或 MRAID 广告隐藏时暂停，恢复可见时才可继续播放效果。
- 使用设备本地字体，无网络字体或外链图片。

参考视频：`Color Block Builder-1080 X 1920-2026-09-18-66358dcf4e39bca21a237eb8b1919f3e.mp4`。

所有运行所需内容已内嵌到单个 `index.html`，可离线打开。物理库与 MIT 许可分别保留于 `source/vendor/matter.min.js`、`source/vendor/LICENSE-Matter.txt`；完整 MIT 许可也保存在交付 HTML 中。
