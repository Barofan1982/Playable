# Worker Rush · 柜台员工升级

2026-10-12。单文件经营试玩，`index.html` 可直接打开，所有模型、规则、界面和操作音效均内嵌，无网络依赖。

## 操作与结局

- 点击餐厅开始接单。点击柜台可优先处理该队。
- 底部 **WORKER** 增加员工，最多 5 人；**SPEED** 提升取餐、行走和备餐速度，最多 3 次。
- 每个员工实际到厨房拿餐，再到对应柜台交付。Sera 身上能看到携带的餐盘和现金。
- 其他员工的收入放在厨房中央收款点。Sera 到收款点收取，购买升级时走到对应购买位置，逐份付钱后生效。
- 服务 **48 位顾客** 成功；**6 位顾客** 等待过久离开失败。订单有耐心环，不是装饰性计时。
- **AUTO PLAY** 使用同一组取餐、送餐、收款与升级规则；可暂停、继续。**RETRY** 重置整个关卡。
- 成功与失败画面停留，直到手动重试。无开张终点、无返回列表链接。

## 实现

固定完整竖屏构图；横屏浏览器把竖屏场景居中展示。WebGL 立体模型与实时阴影，Sera 交替抬腿、弯膝、摆臂。六条柜台队列，八种顾客外观，三种餐品。人工触发操作音效独立有效，页面隐藏时暂停，无 BGM 和音乐开关。

AUTO PLAY 与 RETRY 位于最底部，按钮高度均为 48 px；升级区与控制区分开，底部安全区也会计入间距。短屏与横屏仍完整显示竖屏场景。

维护源码位于 `source/`。`node source/build.cjs` 生成独立 HTML；`node source/check.cjs` 验证规则。
