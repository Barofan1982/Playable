# Juice Sort

独立果汁整理试玩，入口为 [index.html](index.html)。

保留参考的 20 个分层小瓶和左右两个长瓶，使用 Juicy Journey 标识、清亮果汁配色、缓慢上升的透明气泡及玻璃液面动画。

- 点击来源瓶，再点击空瓶或顶层同色的瓶子；仅倾倒顶层连续同色果汁，容量不足时只倒入可容纳部分。
- 左侧收集草莓汁，右侧收集柠檬汁，各达到 22 单位通关。其他颜色用于腾挪整理。
- Auto Play 从当前盘面规划合法操作，可随时暂停；手动点击也会接管。Retry 恢复初始盘面。
- 错误倒入显示叉号，不改变果汁；无路可走显示英文失败提示。
- 成功后先展示结算，再播放 Juicy Journey 静音落版一次，停留最后一帧，Retry 手动重开。
- 没有背景音乐和音乐开关，操作音效独立响应用户交互，页面隐藏时暂停。
- 保留竖屏完整构图，横屏居中显示。单文件内嵌所有运行素材，可离线打开。

验证：自然自动流程 70 次合法倒入，两侧均 22/22，总量保持 82 单位；320×568 与 844×390 实际点按、错误操作及重试通过。
