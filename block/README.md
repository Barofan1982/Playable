# Juicy Journey — Rainbow Block Rush

根据「甜甜-45920-俄罗斯方块-20250410.mp4」制作的 HTML 试玩。

浏览器直接打开 `index.html`。商标、方块图形、动画和操作逻辑均内置，无需联网。

## 操作

- 按住游戏画面左右拖动，选择落点；松手后方块下落。
- 轮廓预览表示当前落点，按 ROTATE 可旋转，按 DROP 可直接下落。右上角 NEXT 显示后续方块。
- 电脑支持左右方向键 / A、D 移动，上方向键 / W 旋转，下方向键软降，空格直接下落。
- 方块碰到底部或已有方块后锁定、保留在棋盘上；只有一整排 36 格全部填满才消除，颜色不影响判定。
- 消除几排，上方方块整体下移几排；没有满排时，落块会堆积，不会触发扫线或自动消失。
- 持续消除，直到初始彩虹墙的方块全部消除后才显示 Good Job!；中途不会按排数弹出结算。新增落块仍按碰撞和满排规则保留，不会为了通关被自动删除。
- 顶部颜色计数和 WALL BLOCKS LEFT 表示初始墙面还剩多少块，进度条表示初始墙面的清理进度。
- 初始地图根据视频起始帧重建：弧形上沿、八条彩虹竖向色带、中部四段横向折返和底部阶梯裂缝。没有预排解题队列。
- I、T、L、J、S、Z、O 每七块组成一组，使用 Fisher–Yates 洗牌；首块从七种形状中随机产生。两组交界也避免相同形状相邻。颜色另外使用八色洗牌，NEXT 预览真实队列。
- 摆放失误会堆积；锁定后任何位置触及棋盘顶部红线，就显示 Game Over 和 TRY AGAIN。若本次填满整排，先完成消除再判定顶部。新方块出生位置被挡住也会失败。
- 失败时点击 TRY AGAIN（电脑也可按 Enter 或空格）会恢复初始地图、计数和进度，并生成新的随机出块队列。
- 清空后可按 NEXT WALL 开始下一面墙，或按 PLAY AGAIN 从第一面重新开始。

## 还原范围

地图按起始帧的方格重建。为留出商标和操作区，裁减了原图顶部空白的两排；填充部分和折线裂缝保留。`map-comparison.png` 为左侧原视频、右侧当前地图的并排对照。

当前使用俄罗斯方块的满排消除、堆积和碰撞规则，出块完全使用随机队列。通关目标是清除初始墙面，允许最后留下新增落块；随机顺序不保证每局都能清空。

方块使用固定视角的 2.5D 绘制，并非原视频的 3D 模型。消除动画和光影仍为本试玩实现，不能称为逐帧 1:1 复刻。

支持手机触控与横竖屏，横屏保留完整的竖向棋盘并在旁边显示说明。商标使用 Juicy Journey，通关口号为 Good Job!。

## 广告跳转

设置全局 `clickTag` / `clickTAG` 或 URL 的 `clickTag` 参数后，通关主按钮跳转到配置的地址；默认按钮为重新开始。失败时的 TRY AGAIN 始终重新开局。

## 自动试玩（2026-10-09）

点击 AUTO PLAY 后根据当前棋盘和下一块选择落点，显示旋转、横向移动和下落。保留原有七种方块随机袋与初始地图，仅填满整排才消除；持续演示至清空初始墙面成功，或堆顶失败。自动操作不保证每局通关。

再次点击可暂停，RESUME 从当前位置继续。手动拖动或按移动键接管操作；RETRY 随时重新开局并停止自动演示。成功或失败后停止，保留结果，等待手动重试。支持手机横竖屏，横屏侧栏提供大按钮。
