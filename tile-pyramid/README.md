# 多层水果金字塔

参考视频2：`Tile Explorer_ Tiles Clear!-720 X 1280-2026-10-12-bfbeb3d1d7b6af8ea3c76ac3dd66b7c9.mp4`，26.11秒。独立可离线运行的单页HTML试玩。

点击没有被上层牌盖住的水果牌，牌会飞入底部七格收纳槽；三个相同图案自动消除。七格装满而没有三同可消时失败。清空全部384张牌获胜。最高层两乘两、下方逐层扩至十乘十，共九层，采用可验证的合法移除序列布牌，每三张同型，整局存在完整解。

底部60px控制栏、48px实际按钮：AUTO PLAY开始自动演示，PAUSE暂停，CONTINUE继续，RETRY从初始牌面重试。自动演示调用与手动相同的取牌与遮挡判断。页面或MRAID广告隐藏时动画、自动操作和操作音效冻结；没有背景音乐或音乐开关。竖屏完整显示，横屏居中，画面不裁切。

## 文件

- `index.html`：内嵌图片与所有逻辑，双击运行，不访问网络。
- `preview.webp`：从实际运行的初始牌面截取。
- `source/template.html`、`source/config.json`、`source/assets/`：独立可编辑源文件与图片。
- `source/build.cjs`：用Node运行，重新生成`index.html`并检查5MB上限。
- `sample.json`：合集卡片元数据。
- `ASSET-NOTES.md`：图片来源与处理说明。
- `package-checks.json`：单页与本地归档的一致性和体积记录。

## 验证接口

浏览器提供`window.__qa`（亦可用`window.__playable`）：`state()`、`startAuto()`、`reset()`、`tap(id)`、`solve()`、`step()`、`fail()`、`pause()`。`solve()`依次调用真实规则完成初始关卡，`fail()`执行合法的不同图案取牌直至七格满，不直接写入终局。`state()`返回剩余牌、可取牌和被盖牌ID、收纳槽、操作数及当前阶段。
