# Juicy Journey · Island Merge & Cook

## 打开与操作

直接打开 `index.html` 即可离线试玩。图片、商标和奖励素材均已嵌入 HTML，无需安装或启动服务。

- 将一个物品拖到另一个相同物品上，松手后两块一起消除。两个物品可以位于不同位置。
- 消除后，同列上方物品下落，不生成新的物品。
- 拖到不同物品上或棋盘外会返回；单击只选中物品，不会消除。
- **HINT** 高亮一对相同物品，不会替玩家消除。
- 每完成 3 对配对，触发一次烹饪奖励，依次为烤箱、食材篮和烤架。物品下落完成后重新确定奖励位置，范围会先高亮，再消除对应物品。
- 当剩余物品已互不相同，会出现 **COOK THE LAST INGREDIENTS**，点击后按局部范围分批烹饪，每批最多 4 个，自动继续直到清空棋盘。
- **AUTO PLAY** 自动完成配对、奖励和最后的烹饪，直到全部 91 格清空。
- 完成后播放食材飞散效果，再保持最终海岛人物画面，不弹出结算或重试窗口。
- 只有点击 **RETRY** 才重新开始。自动操作或动画中也可以重试。
- 右上角声音按钮可开启或关闭音效，默认关闭。

## 参考与还原范围

参考视频：`Flambé®_ Merge and Cook-360 X 640-2026-09-23-765a534486d0e4249ffc9565e87a590c.mp4`，360 × 640，约 45.55 秒。

本样本还原了视频的 7 列 × 13 行密集棋盘、初始物品排列、相同物品拖拽配对、按列下落，以及烤箱、食材篮、烤架的放大反馈。普通物品图标从参考视频中提取，品牌使用 Juicy Journey。

为使试玩能够完成到最后，加入了提示、自动演示、手动重试和最后一批单个食材的烹饪。奖励频率和消除范围为本试玩实现：烤箱覆盖附近 3 × 3，食材篮覆盖附近 5 行 × 3 列，烤架覆盖附近 3 行；实际范围受棋盘边界和剩余物品影响。

画面使用具有 3D 风格的位图素材和 Canvas 动画，没有运行真实 3D 模型。底图直接使用用户提供的 `JJ-en-新落版2k-60fps.mp4_20261008_105632.744.png`，保留原图颜色与完整构图。人物本身保持静态，物品合并、下落、奖励、闪光和飞散由页面绘制。
