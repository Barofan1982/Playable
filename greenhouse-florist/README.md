# Juicy Journey · 双层温室花店

登上双层温室采集粉色郁金香，每三朵包装为一盆，再搬下楼出售；逐步扩充三片花田。

## 操作

拖动移动 Sera，或者点地面目的地；键盘可用 WASD / 方向键。停在地面标识处拿货、放货、收钱、付费。TEAM / BUILD 列出全部阶段，选择后 Sera 必须走到对应地点才能支付。AUTO PLAY 可演示全流程。音乐默认为关闭，点击 ♪ 开启。

## 经营目标

共 10 个付费阶段、5 名付费员工。按顺序经营和扩建，扩建全部完成后继续接待顾客。没有额外的开张付费任务，也不会自动弹结算或冻结场景；只有手动 RETRY 才会重开。人数与销售统计始终显示在顶部。开局已有包装员和接待员、两路自动售卖；可携带 72 朵花或 24 盆成品，升级后为 144 朵 / 48 盆，并扩为四路售卖。

货物来自实际库存，员工背着货物运输；收入先堆在售卖点，收款员工背回 BANK，Sera 需要去领走。逐步付款保留已付金额。
