# Shelf Sort · Juicy Journey

独立 HTML 货架整理试玩。三关依次整理 4、5、5 组商品，使用 Juicy Journey 本地商品美术及原创海岛小店货架。

## 操作

- 拖动一件商品到空位；也可先点商品，再点目标隔间。
- 每个隔间 3 个位置，允许不同商品暂存。同类商品凑齐 3 件后打包出货，腾出该隔间。
- 每次有效移动消耗一步；放到满格或柜外不扣步数。
- 三关步数预算为 22、25、26。完成当前关显示 Next Shelf，全部完成显示 Good Job；步数耗尽显示 Try Again。
- Auto Play 使用当前盘面的合法操作，支持手动调整后继续求解；再次点击暂停，触摸盘面可接管。自动模式完成一关后继续下一关。
- Retry 重开当前关；全部完成后 Retry 从第一关重开。
- 不设倒计时，结束画面保持到用户操作，无跳转、返回列表或下载入口。

## 画面与资源

暖木色层板、青绿色柜架和店铺背景由 Canvas 独立绘制。商品保持原始长宽比，底部对齐货架，使用接触阴影及层板前沿遮挡。货架和规则代码均独立编写，未使用参考 HTML 的代码、场景、美术或关卡布局。

商品为本地汽水、椰奶、拿铁、爆米花、蓝莓杯子蛋糕、牛奶。素材来源记录保存在本地 `source/asset-manifest.json`。

## 独立运行

直接打开 `index.html`，所有资源内嵌，无网络依赖，低于 5 MB。英文界面；保留人工触发的轻音效，无 BGM 或音乐开关；页面隐藏时暂停动画、自动操作及音效。竖屏构图在宽屏浏览器中完整居中显示。

源文件位于本地 `source/`，执行 `node source/build.cjs` 重建。独立逻辑和浏览器交互检查记录也保存在该目录。本地归档位于合集 `下载包/shelf-sort.zip`。
