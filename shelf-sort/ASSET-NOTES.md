# Shelf Sort asset notes

This sample is an original implementation of a three-slot shelf-sorting puzzle. The user-provided Flower Sort HTML was inspected as a reference for the familiar grouping interaction. Its code, flowers, baskets, mountain scene, UI, level layouts and animations are not included.

The cabinet, shelf surfaces, contact shadows, shop setting, packing animation, interface and sound effects are independently drawn or synthesized in the new sample. No background music is embedded.

Product artwork comes from the user's local Juicy Journey chess-item collection. Soda, coconut milk, latte, popcorn, blueberry cupcake and milk were trimmed to their transparent artwork bounds, resized without changing proportions, and encoded as WebP. Isolated stray pixels outside the popcorn artwork were removed. A two-pixel transparent safety border remains. Source paths and processing metadata are archived in `source/asset-manifest.json`. The logo uses the existing Juicy Journey logo.

The gameplay uses no character or character animation. The standalone HTML has no remote runtime resources.
