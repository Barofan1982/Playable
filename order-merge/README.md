# Order Merge · Juicy Journey

根据用户提供的 `JJ-en-254-merge多订单提交-赵翰禹-S-v1-20260902.mp4` 制作的独立竖屏试玩。使用本地 Juicy Journey 角色、棋子与统一落版。

## 玩法

- 7 列 × 9 行棋盘，保留左上及右下粉色爱心区域；开局 58 件物品。
- 三步首单引导：中央两桃子合成 → 左右两瓶牛奶合成 → 双击奶油提交整单；提示居中放大，各步都有对应的拖动或连续双点手指演示。按实际盘面推进，反向拖动或挪动材料后仍追踪当前物品，首单完成后结束。操作时引导让开，Auto Play 时隐藏，Retry 恢复。
- 开局不放置四位顾客要求的任何成品；八件订单物品全部需要由低级材料合成。对应材料数量已配齐，标准流程无需额外补料。
- 拖动两件相同、同等级道具，合成一个升级道具。原位置留空，其他格子保持原位，不下落补齐。
- 可以把物品移到空格、交换不同普通物品；点击选中后再点击目标也能操作。
- 顶部同时展示两个订单，每单需要两件成品。已有成品会变绿并显示勾选；两件齐全后，可以双击棋盘上任意一件对应成品，或点击绿色 Serve，提交整单。手机支持连续双点；单击仍用于选中，拖动仍可合成。
- 交付同时消耗订单的两件成品，先飞向需求图，再让金币飞向顶部钱包；单纯合成不会发金币。
- 顾客依次为 Sera、Kai、Zoey、Sophia，采用半身构图。前一位交付后，后续订单向左递补。
- 四单奖励为 120、140、120、180，总计 560 金币。目标为完成全部四单，棋盘无需清空。
- 食品合成和生成原料消耗 1 能量。资源合成不消耗体力：两份双闪电合成一份三闪电，两份双钻合成一份三钻堆。
- 体力和钻石必须双击领取，单击仅选中、拖动可以合成；合成后不会自动领取。基础资源每份 15，合成后每份 30，领取只结算一次。
- 备菜台在空位生成当前订单所需链的基础物料。体力为零时，只要棋盘上还有体力资源，仍可先合成或双击领取后继续。
- 能量耗尽且无可领取能量、无可直接交付订单时显示 Try Again；Retry 重开。

## 自动试玩与结尾

Auto Play 根据当前盘面选择合法合成、补料、交付操作；支持暂停、继续及手动接管。标准路径是 8 次合成、4 次双物品交付，奖励全部到账后显示 Perfect。

结算至少保留 2.6 秒，再完整播放 5 秒静音 Juicy Journey 落版，保持最后一帧，手动 Retry 才重开。没有返回列表或下载按钮。

## 素材与显示

游戏人物、食品、资源和备菜台均采用本地原始素材，统一裁切透明边、保留比例与原有立体质感。棋盘、暖色店铺背景、订单 UI、动画与操作逻辑独立实现；未将整段参考视频当成玩法播放。

依据视频重建双订单、棋盘构图与交付节奏；原片部分香草和海鲜占位物改为本地爆米花原料与水果，并提供可重复操作的合成链及备菜台。源码与逐帧参考保存在本地 `source/`。

英文界面，单文件离线运行。没有 BGM 或音乐开关；轻音效由用户操作触发，页面或广告隐藏时暂停。竖屏画面在横向浏览器中完整居中显示。
