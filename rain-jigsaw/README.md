# Juicy Journey · Jigsaw Puzzle · 雨夜撑伞版

## 打开与操作

直接打开 `index.html`。原始图片与商标嵌入在 HTML 中，完成后的动态效果由页面绘制，可以离线试玩，无需安装或启动服务。

- 当前阶段的全部未放置拼块都在底部备选栏中：第一阶段 10 块，第二阶段 14 块。
- 左右滑动底部栏即可浏览、选择任意拼块，无需先消耗当前可见的拼块。鼠标横向拖动或滚轮也可浏览。
- 向上拖出拼块，再移动到对应缺口，松手后正确的拼块会吸附。
- 放错位置、拖出棋盘或中断拖动，拼块会返回原位。
- HINT 只高亮一块拼图和它对应的缺口，不会代替玩家完成。
- 点击 **AUTO SOLVE**，每秒自动放入一块，连续完成两个阶段；已经手动拼过的进度会继续保留。自动过程中按钮显示 AUTO…，不能重复启动。
- 完成动画播完后，画面一直停留在最后一帧，不弹出结算或重试窗口。
- 点击底部 **↻ RETRY** 或右上角 ↻ 才重新开始；自动拼图中也可以手动重试。
- 左上角使用 Juicy Journey 商标。
- 声音默认关闭，可用左下角按钮开启拼块音效。
