# Juicy Journey · 层叠麻将配对

按麻将接龙规则配对 68 张牌：上方无遮挡且至少一侧空着才能选择。五次错配、无法配对或时间耗尽会失败。

## 操作与规则

Match identical FREE tiles · one side must be open

点击两张相同且自由的麻将。自由牌要求上方没有压着其他牌，并且左侧或右侧至少一边为空；两次洗牌保留剩余牌的种类与数量。

- 成功：68 张麻将牌全部配对清空。
- 失败：五次错配、无可用配对且洗牌耗尽，或超时。
- 本轮限时：120 秒。
- AUTO PLAY 使用与手动操作相同的规则，可随时暂停；手动操作会暂停自动演示。
- 成功或失败直接显示简短提示；画面保留到手动 RETRY，不跳转其他试玩。结尾动画最长 0.7 秒。
- 音乐默认关闭，点击 ♪ 开启，重试保留声音设置。
