# Juicy Journey · 落石通道救援

落石持续从上方逼近。消除相邻同色图块，让 Sera 沿楼梯前进并清除出口的 70 块障碍；落石碰到人物会立即失败。

## 操作与规则

ROCKS keep falling · match 2+ tiles to open the EXIT

点击至少两个上下左右相邻的同色图块；孤立图块不能消除。石板、水位、火势或闸门随着实际操作变化。彩球灭火还需要手动点击充满后的横杆。

- 成功：70 块出口障碍清空，Sera 逃离落石区域。
- 失败：落石接触人物、时间或移动步数耗尽。
- 本轮限时：65 秒，40 个有效操作步数。
- AUTO PLAY 使用与手动操作相同的规则，可随时暂停；手动操作会暂停自动演示。
- 成功或失败直接显示简短提示；画面保留到手动 RETRY，不跳转其他试玩。结尾动画最长 0.7 秒。
- 音乐默认关闭，点击 ♪ 开启，重试保留声音设置。
