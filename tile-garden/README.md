# 花园连线收集

参考第 4 段 Tile Explorer 视频：7×11 密集花草牌面与六张数量目标牌。按住一张牌，拖过水平、竖直或斜向相邻的同样花朵；至少连接三张后松手收集。选中牌逐张发光、飞入目标牌，数量逐张扣减；剩余牌按列下落，顶部由固定供应序列补入。

原始六张目标数量保留为：黄玫瑰 18、郁金香 3、鸢尾花 12、红玫瑰 21、双色花 14、粉百合 3。22 步内完成全部目标即成功，用完步数或无合法三张连线则失败。非目标花草也可以合法消除，但不会减少目标数。

AUTO PLAY 按真实连线规则逐张选择并执行，共 15 步合法完成本局。Pause / Continue 可以暂停继续；后台隐藏时玩法、动画和音效都冻结。没有背景音乐。竖屏按视频比例完整展示，横屏时居中留出侧边。

## 文件

- index.html：所有美术内嵌的独立离线 HTML，小于 5 MB。
- preview.webp：初始真实画面。
- source/build.cjs、source/rules.js、source/app.js、source/template.html、source/assets/：可维护源码及真实素材。
- source/check-deck.cjs：检查自动解法每一条路径的相邻性、同花与真实列下落。
- ASSET-NOTES.md：素材来源与规则核实。

重新构建：node source/build.cjs。素材首次同步从维护工具的参考提取清单读取，拷贝到本样例 source/assets；发布 HTML 不需要任何外部文件。

验证接口：window.__QA / window.__PLAYABLE 提供 state()、startAuto()、reset()、tap(index)、solve()、step(ms)、fail() 与 hooks.commit(path)。solve() 返回合法相邻同花路径；commit() 始终验证路径后才收集。
