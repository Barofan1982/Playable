# 水果填色收集

参考第 3 段 Tile Explorer 视频：店铺背景、蓝色吊灯、7×7 厚奶油白水果牌与上方水果轮廓。点击当前目标水果，每收集一个填入三分之一颜色；收集三次后进入下一种水果。樱桃、葡萄、香蕉、西瓜、蓝莓、柠檬全部完成后成功。

顶层牌被拿走后原位置露出预设的暗色下一层图案，不发生下落或随机补牌。暗色底牌不能继续点击。选错三次失败；点击 Retry 手动重开。

底部 AUTO PLAY 自动执行合法收集，Pause / Continue 可以暂停继续；后台隐藏时玩法、动画和音效都冻结。没有背景音乐。竖屏按视频比例完整展示，横屏时居中留出侧边。

## 文件

- index.html：所有美术内嵌的独立离线 HTML，小于 5 MB。
- preview.webp：初始真实画面。
- source/build.cjs、source/app.js、source/template.html、source/assets/：可维护源码及真实素材。
- ASSET-NOTES.md：素材来源与规则核实。

重新构建：node source/build.cjs。素材首次同步从维护工具的参考提取清单读取，拷贝到本样例 source/assets；后续发布 HTML 不需要任何外部文件。

验证接口：window.__QA / window.__PLAYABLE 提供 state()、startAuto()、reset()、tap(index)、solve()、step(ms)、fail() 和暂停、隐藏、坐标映射 hooks。solve() 只选择当前盘面合法的目标牌。
