# Juicy Journey · 玉米旋转消除

浏览器直接打开 `index.html`，可以离线试玩。

- 左右拖动一个圆环，只转动所选的一行。
- 对齐同色连线后，沿连线拖曳消除，产生爆米花效果。
- 画面使用统一的 2.5D 俯视角；支持横竖屏和声音开关。
- 结尾口号为 Good Job!，可选 PLAY AGAIN 重玩或 KEEP POPPING 继续。

参考 Tasty Travels_ Merge Game · 720 × 1280 视频，品牌为 Juicy Journey。
