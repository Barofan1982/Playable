# Juicy Journey · 玉米旋转消除

浏览器直接打开 `index.html`，可以离线试玩。

- 左右拖动一个圆环，只转动所选的一行。
- 对齐同色连线后，沿连线拖曳消除，产生爆米花效果。
- 画面使用统一的 2.5D 俯视角；支持横竖屏和声音开关。
- 结尾口号为 Good Job!，可选 PLAY AGAIN 重玩或 KEEP POPPING 继续。

参考 Tasty Travels_ Merge Game · 720 × 1280 视频，品牌为 Juicy Journey。

## 自动试玩（2026-10-09）

点击 AUTO PLAY 后逐行转动对齐颜色，再沿同色连线拖曳消除，完成三组目标。仅所选圆环旋转，消除仍经过原有匹配判定与爆米花动画。

再次点击可暂停，RESUME 从当前位置继续。手动拖动或按移动键接管操作；RETRY 随时重新开局并停止自动演示。成功或失败后停止，保留结果，等待手动重试。支持手机横竖屏，横屏侧栏提供大按钮。

已检查触屏开始、暂停继续、重试、手动接管、结束保持及四种屏幕尺寸。`autoplay-checks.json` 为本地检查记录。
