# Juicy Journey · 海岛酒店经营

基于 2026-10-02 的 b2bc1719 参考视频制作的独立 HTML 试玩。采用俯视 2.5D 的海岛酒店场景。在参考视频的收款、建设和区域解锁基础上，扩展为大厅、咖啡区、泳池和客房四个经营阶段，10 项建设与升级，完整 AUTO 演示约 3 分半，本次实测约 3 分 30 秒。

## Sera 与搬运更新（2026-10-03）

现金堆随走路摆动；收银员的钱先堆在 BANK。STAFF 和 OPEN HOTEL 只选择目的地，Sera 到场停下后逐叠付款。原有两趟首桌、库存搬运及入住条件保留。

移动主角采用同一套本地 Sera 3D 模型：橙红侧辫、绿色眼睛、雀斑、青色蝴蝶结、黄色荷叶上衣、青色花裙和棕色凉鞋；转身、摆臂和步行保留。顾客和员工继续使用不同外观。

## 试玩

直接打开 `index.html`，无需联网或安装依赖。

- 按住画面拖动操纵杆移动；也可以点击地面自动走过去。电脑支持 WASD 和方向键。
- 走近地面绿色现金或收款区会自动拾取，现金叠在角色背后。
- 站在购买框中自动投入现金，每次扣款都对应背包余额；余额不足时保留已投入金额。
- 第一处鸡尾酒桌台需要 60，开局每趟最多搬 30。先收款并投入一半，再收一趟完成建设；提示和现金背包显示当前进度。
- 依次建设鸡尾酒吧、花园休息区、吧台助手、VIP 前台、泳池、池畔果汁吧、遮阳躺椅、两间客房和开业装饰，基础建设总投入 6,710，其中 Grand Opening 为 3,000；收款与清洁 NPC 为额外的可选雇佣。
- 经营成果会开放后续任务：完成鸡尾酒订单、接待客人、泳池消费与客房入住。现金足够也不能跳过任务条件。
- 吧台每次服务消耗一份真实库存。走到吧台后方的补货区领取最多 12 杯饮品，再带到交付区逐杯补入吧台；聘请助手后，助手会亲自往返补货。
- 客人购买饮品后走到空闲椅子，落座后消费；泳池客人步行到池边，再进入泳圈游泳；入住客人从前台走到客房并休息。客人完成自己的行程后才计入满意人数，同一个客人只计一次。
- 退房后可亲自清洁，也可付 300 雇佣清洁员，让它走到房间并清洁。房间恢复后才接待下一位客人；第二间客房可直接付 450 建设，两间房合计完成至少五次住宿作为开业条件。
- 开局 42 位客人，12 种外观使用洗牌随机顺序；新客人持续抵达，客人移动到画面外再离开。
- STAFF 按钮打开员工菜单：大厅收款员 150、吧台收款员 200、花园收款员 200、泳池收款员 250、清洁员 300，合计 1,100。对应营业区建好后可选择雇佣，Sera 会走到对应员工的付款点，停下后逐叠支付；收款员真实往返营业区和前台，搬运并存入 BANK 收款点；Sera 靠近取走才成为随身现金，搬运中的现金也纳入账目。AUTO 会逐步雇佣这些员工。
- 收到钥匙后走近泳池入口，实体双扇门向两侧打开，门板在动画中仍有碰撞。门板、立柱与入口连接墙的显示和行走碰撞一致。
- AUTO PLAY 自动完成整个经营流程；PAUSE 随时交回手动操作。
- 开业条件为完成前九项建设、资金 3,000、满意客人 110、已服务客人 110，以及完成住宿 5 次。顶部持续显示三项人数进度，顶部任务栏显示资金进度与紧凑的 OPEN HOTEL 按钮，三项人数条件位于按钮上方；缺少条件时按钮不可用，底部提示说明当前任务。移除了遮挡酒店场景的开张横幅。达标后点 OPEN HOTEL，Sera 会背着现金走到开张垫，停下后逐叠投入剩余金额开张。完成 10 项建设后显示 Good Job!，镜头平滑拉远展示酒店全景并定格。结尾显示实际满意人数。只有手动 RETRY 才重开，不跳转其他试玩。
- 左下角音乐开关同时控制背景音乐和收取现金、消费、建造的音效。默认静音。

## 音乐和体积

使用用户提供的 Ever So Blue - Onthou，截取开头 30 秒，MP3 / 128 kbps / 循环播放，内嵌在 HTML 中。图片使用已压缩的 Juicy Journey 标识；场景、人物和设施由本地几何体绘制。

HTML 和 ZIP 均以 3,000,000 字节为上限。实际体积与一致性见 `package-checks.json`。

## 本地构建与检查

`source/build.cjs` 生成 HTML 并调用合集的压缩与音乐工具；`source/check.cjs` 在独立浏览器检查真实触摸、点击、四种窗口尺寸、现金收支、两趟开局、分批付款、泳池门开合与进出、库存补货、四种自动收款 NPC、清洁 NPC、客人落座、游泳、入住、四项可见开业条件、开张按钮、完整自动演示、音乐和完成画面。报告为 `checks.json`。时长由完整经营流程决定，没有额外倒计时限制。

`source/package.py` 生成合集下载目录内的 ZIP，并校验 HTML 与包内版本一致，以及下载包和当前 HTML 保持一致。


## 步行动作修正（2026-10-03）

Sera 的肩、肘、手掌与髋、膝、脚踝联动，左右脚轮流抬起与落地，双臂反向摆动；背货时保留摆臂。花裙分片摆动，侧辫随步伐摆动，上身轻微前倾。步伐按实际移动距离推进，停止后平滑回到站姿，重试重置动作。动作由本地几何体实时计算，没有增加外部素材。

`walking-checks.json` 记录实际渲染关节的四方向移动、载货迈步、摆臂、停步与重试检查；连续截图存于 walking-preview。
