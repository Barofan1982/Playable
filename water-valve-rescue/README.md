# Juicy Journey · 双水阀与熔岩救援

两间连续机关房：先用黄色图块打开清水闸灭火，再放水冷却熔岩形成出路。消除过多红色图块会打开危险闸。

## 操作与规则

YELLOW opens clean water · 8 RED opens the lava valve

点击至少两个上下左右相邻的同色图块；孤立图块不能消除。石板、水位、火势或闸门随着实际操作变化。彩球灭火还需要手动点击充满后的横杆。

- 成功：两间机关房完成，Sera 沿冷却的出路离开。
- 失败：打开危险闸、时间或步数耗尽。
- 本轮限时：85 秒，48 个有效操作步数。
- AUTO PLAY 使用与手动操作相同的规则，可随时暂停；手动操作会暂停自动演示。
- 成功或失败直接显示简短提示；画面保留到手动 RETRY，不跳转其他试玩。结尾动画最长 0.7 秒。
- 音乐默认关闭，点击 ♪ 开启，重试保留声音设置。
