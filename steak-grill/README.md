# Steak Grill · 海边牛排烧烤

独立离线 HTML 试玩，保持完整竖屏构图；横屏浏览器居中呈现。

## 操作

- 点击下方生牛排托盘，依次放入三个烤位。
- 烤位环形指示由金色变绿后，点击牛排夹到空盘子；过久会变焦黑。
- 点击番茄酱瓶选中，再点击需要加酱的盘子。顾客订单中每片牛排单独标出是否加酱，划线的酱瓶表示禁酱。
- 准备齐后点击带餐罩图标的 SERVE。数量、熟度、番茄酱均独立检查。
- 累计三次错误失败；完成五单成功。结果保持，点击最下方 RETRY 重试。
- AUTO PLAY 以相同操作规则逐份烹饪出餐，可暂停、继续，手动操作可接管。

顾客依次为海鸥、Zuri、Oli、Chloe、Zuri。Sera 仅出现在结果层。初始双份禁酱、三份加酱、双份一份禁酱一份加酱、三份禁酱、双份加酱。

没有背景音乐、音乐按钮、返回列表或开张环节。操作音效在用户操作后有效，隐藏页面暂停。

## 规则与检查

5.2 秒开始熟透，8.9 秒开始焦糊；离开烤位后停止烹饪。自动操作选择 6.5 秒以上的熟牛排，遵守烤位/盘子容量与逐片酱料要求，不直接修改订单或成功状态。五单自动流程约 45 秒。

维护源码在 `source/`，运行 `node source/build.cjs` 生成单文件。`node source/check.cjs` 验证自动通关、夹生/焦糊/错酱拒绝、三次错误失败、暂停与结束保持。
