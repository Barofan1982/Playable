# 石牌连锁 · Stone Tiles

对应用户提供的第 1 条 Tile Explorer 视频。灰色深石槽、粉灰颗粒石面、果实图案、厚石砖、坠落和碎屑均围绕原片制作。

打开 `index.html` 即可离线游玩。点击一列，顶部石牌落入该列；落下的石牌碰到相同图案时一起粉碎，上方石牌随重力继续下落并产生连锁。清除 42 块完成这一小局。连续错误投放会把某列堆到石槽上沿，产生真实满槽失败。

底部 `AUTO PLAY` 使用相同投放操作逐步示范；`PAUSE` 暂停，`CONTINUE` 继续，`RETRY` 重玩。按钮触控高度 48 CSS 像素。竖屏完整显示，横屏居中。没有背景音乐和音乐开关；用户操作启用干燥落石与碎石音效。页面隐藏或 MRAID 广告不可见时，自动投放、动画、物理进度和声效均暂停；MRAID 加载态等待 `ready`，同时响应 `viewableChange` 与 `stateChange` 的隐藏态，只有页面和广告均可见时才恢复。

发布 HTML 内嵌所有位图和代码，不依赖网络。`source/build.cjs` 从 `source/index.template.html`、`source/style.css`、`source/game.js` 和 `source/assets/` 构建 `index.html`。修改后运行：

```powershell
node source/build.cjs
```

`window.__playableQA` 与 `window.__qa` 提供 `state()`、`reset()`、`tap(column)`、`drop(column)`、`startAuto()`、`pause()`、`resume()`、`step(milliseconds)`、`solve()`、`fail()`。列从 0 到 7。`fail()` 实际连续向左列投入不匹配牌直到满槽；`solve()` 开始逐步自动投放。

视频是视觉与动作参考，试玩根据可见过程还原接触匹配及重力连锁，并为短局增加目标和结束反馈；不声称复刻原游戏全部关卡规则。图像来源和授权说明见 `ASSET-NOTES.md`。
