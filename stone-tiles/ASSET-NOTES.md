# 图像与材质来源

- 参考视频：`Tile Explorer_ Tiles Clear!-720 X 1280-2026-10-12-7a25f55c2e63d796a377e61ccfced6d9.mp4`，用户本地提供，720×1280，约 30.12 秒。
- `source/assets/wall.webp`：参考视频 0.10 秒中无图标的灰色石槽底面区域，以镜像拼接保留原始石纹比例，添加深槽遮光与暗边。
- `source/assets/granite.webp`：同一帧粉灰石牌的无图标顶部纹理小块。试玩使用该颗粒纹理并添加光照、边角、石材厚度和细小裂痕。
- 果实位图来自本项目统一提取并整理的参考果实资产，保持原片果实类别、颜色、立体高光及描边。没有使用 emoji 或在线图标库代替。
- 碎石粒子使用各块石砖的实际颗粒石材表面作为图像源，果实图案在粉碎时消失；每块石牌生成 36 片带厚边的粗糙碎石，并按重力坠落、旋转和短暂反弹。
- 声效以浏览器 Web Audio 实时合成，无音乐文件、音乐播放器或 BGM 开关。

这些参考物料属于用户提供的游戏广告素材。本项目用于内部效果还原和试玩评估；素材权益仍归原权利人。对外发行前需由发行方确认其素材使用权限。
