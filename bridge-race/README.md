# Juicy Journey · Snow Bridge Race

更新：2026-10-11。独立雪球搭桥竞速试玩，商标、3D 模型、规则和操作音效均内嵌在 index.html 中，单文件离线可玩。

## 当前设计

- Sera 主角：橙红侧辫、青色蝴蝶结、黄色上衣、青色花裙和棕色凉鞋，保留步行动作。
- 三段连续雪地赛道、四条雪阶通道，与三名对手争夺终点。
- 按用户反馈，移动与雪球转动速度降为首版的三分之一；主角 1.3 世界单位/秒，对手按相同比例减速。步行动作依据真实位移推进。
- 雪球自转按实际位移累计，半径变大或变小时不再跳转角度。
- 统一使用浅色雪地、白色雪球和浅蓝色压雪痕迹；移除木材、黑色块材、大理石材质及深色地面痕迹。
- 起步携带 8 份积雪。滚过雪地收集积雪，雪球增大；每铺一级雪阶消耗一份，雪球缩小。携带上限 36，每段 28 级，共 84 级。
- 未铺设雪阶不能通过；缺雪时返回当前平台收集。积雪补充间隔与移动速度同步调整为 36 秒。
- 倒计时同步延长到 315 秒，避免减速后被原计时提前结束。
- 第一名到达终点成功；对手先到、失足或计时结束失败。结果保持，只有手动 RETRY 才重新开始。

## 操作

手机在盘面按住拖动，通过虚拟摇杆控制 Sera；松手停止。电脑支持方向键/WASD。

AUTO PLAY 自动收集和铺阶，再次点击暂停整场比赛，再点继续；手动移动接管自动操作。页面不可见时停止比赛推进及声音。

完整竖屏构图，横屏浏览器居中显示并留两侧空间。独立试玩没有返回列表入口。

## 音效

仅保留收集、铺阶、成功和失败的短音效。无 BGM、无音乐数据或音乐开关。

## 参考与实现范围

参考用户提供的 Bridge Race 视频中收集材料、滚动携带、消耗铺阶和上楼比赛的关系。按最新反馈改为统一雪地、雪球表达。Sera 和其他角色、积雪、楼梯、奖杯及场景由本地 WebGL 绘制，未把原片截图作为运行素材。

## 验证与归档

核对随机开局的自动通关、84 级雪阶和所有角色的“收集数 = 已消耗 + 携带数”。检查缺雪不能通过、两份积雪仅铺两级、对手获胜失败、真实手机拖动、自动暂停继续、成功保持、失败提示和手动重试。四种视口核对控件和页面边界。100 个随机开局均自动通关，真实浏览器全程约 65 秒；暂停保持雪球角度，连续 101 帧自转检查无跳变。
