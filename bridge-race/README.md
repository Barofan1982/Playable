# Juicy Journey · Snow Bridge Race

更新：2026-10-11。独立双人雪球搭桥竞速试玩，3D 模型、规则和操作音效均内嵌在 index.html 中，单文件离线可玩。

## 当前设计

- Sera 与一名蓝色对手进行双人比赛，三段连续雪地赛道、两条雪阶通道。
- 两名角色开局均为 0 份积雪。每拾取一个雪点仅增加 1 份，收集间隔 0.24 秒。每铺一级雪阶消耗 1 份，携带上限 36，每段 28 级，共 84 级。
- Sera 保持 3.9 世界单位/秒的移动速度，对手为 2.1–2.37。步行动作随位移推进，雪球自转独立乘以三分之一。
- 使用浅色雪地、白色雪球和浅蓝色压雪痕迹。每个有效雪点均可见，空载时不显示携带雪球。
- 移除倒计时、排名、积雪数、人物标签、进度栏和解释性文字。手机竖屏游戏画面铺满屏幕；横屏保持完整竖屏构图，居中留两侧空间。
- 仅保留角落的自动播放和重试图标，触控面积各 48 × 48 px。
- 缺雪不能跨过未铺设的雪阶；雪点 12 秒补充。没有隐藏的时间限制。
- 先到终点成功；对手先到或失足失败。简短结果提示保留最终场景，只有手动重试才重新开始。

## 操作

手机按住盘面拖动，以虚拟摇杆控制 Sera；松手停止。电脑支持方向键/WASD。

角落 ▶ 启动自动收集和铺阶，Ⅱ 暂停整场比赛，再点继续；手动移动接管自动操作。↻ 手动重玩。页面不可见时停止比赛推进及声音。

独立试玩没有返回列表入口，也不提供下载按钮。

## 音效

仅保留收集、铺阶、成功和失败的短音效。无 BGM、音乐数据或音乐开关。

## 参考与实现范围

参考用户提供的 Bridge Race 视频中收集、滚动携带、消耗铺阶和上楼比赛的关系，并按用户要求调整为双人沉浸式雪地场景。Sera、对手、积雪、楼梯、奖杯及场景由本地 WebGL 绘制，未把原片截图作为运行素材。

## 验证与归档

检查两名角色初始全部为零、每次拾取增加一份、84 级雪阶和材料守恒，缺雪不能通过、两份积雪仅铺两级、对手先到失败。400 次跨帧率规则模拟全部通关，约 34–39 秒；真实浏览器约 35 秒。核对真实手机拖动、自动暂停继续、完整通关、成功保持、失败提示、手动重试及四种视口的页面边界。
