# Juicy Journey · 水塔排水救援

消除各列图块来击碎水塔底部八块石板，形成排水口。水位降下后 Sera 脱困；水满或步数耗尽则失败。

## 操作与规则

Blast each column to crack its stone plate · drain the tank

点击至少两个上下左右相邻的同色图块；孤立图块不能消除。石板、水位、火势或闸门随着实际操作变化。彩球灭火还需要手动点击充满后的横杆。

- 成功：八块石板击碎且水塔排空，Sera 脱困。
- 失败：水位达到危险线、时间或步数耗尽。
- 本轮限时：65 秒，32 个有效操作步数。
- AUTO PLAY 使用与手动操作相同的规则，可随时暂停；手动操作会暂停自动演示。
- 成功或失败直接显示简短提示；画面保留到手动 RETRY，不跳转其他试玩。结尾动画最长 0.7 秒。
- 音乐默认关闭，点击 ♪ 开启，重试保留声音设置。
