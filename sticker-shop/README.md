# Juicy Journey · Sticker Shop

更新：2026-10-08。独立的贴纸商店装饰试玩；所有素材、配乐和脚本均嵌入 `index.html`，可直接离线打开。

## 操作

- 底部从一开始就包含全部 36 张未放置贴纸，左右滑动选择。
- 上下拖动贴纸进入房间，所选物品的位置会出现半透明形状和沿贴纸实际边缘的绿色轮廓；靠近目标松手后吸附。
- 放错位置会动画返回，不增加进度。商品先放对应的货架，收银机和面包先放柜台。
- 也可以选择贴纸，再点击目标位置放置。键盘 Enter 或空格可选择当前聚焦的贴纸。
- HINT 选择可用贴纸并指出位置；不会替玩家放置。
- 空白处拖动平移；双指捏合、鼠标滚轮或 + / − 缩放，范围 1–3.2 倍；FIT 恢复完整场景。
- AUTO PLAY 按家具依赖顺序逐个放置，支持暂停和继续；暂停后当前在途贴纸落位，后续停止。
- 36 张全部到位后，播放不超过 0.85 秒的完成反馈，显示 Good Job!，保留完成后的房间。只有手动 RETRY 才重开。
- 音乐默认关闭；♫ 只控制内嵌背景配乐；操作音效默认有效，第一次手动操作即可发声。配乐为用户提供的 Ever So Blue - Onthou，前 30 秒、MP3 128 kbps 循环。

## 本次画面与声音修正

- 空调和窗户作为独立贴纸，开局墙面留空。
- 家具、商品与人物统一使用白色贴纸外描边；位置提示按实际透明轮廓显示，梯子空隙也保留。
- 五个柜子替换为用户于 2026-10-08 确认的设计：四层双格木柜、三层冷藏柜、三层果汁柜、三层中岛陈列柜和收银柜台；透明空柜图与确认稿逐字节一致。
- 柜子与已贴商品按同一组立体坐标一起绘制。背板、侧板、柜顶、中间隔板、层板按实际深度遮挡瓶罐，商品不再统一压在柜子最上层。
- 重新安排各层的商品位置、间距和高度；瓶罐、纸盒、水果和柜台物件落在对应支撑面，保持层间余量。接触阴影也投影在该支撑面上。
- 独立家具和人物的阴影落在地面；阴影不参与贴纸轮廓。已渲染的柜子组合会缓存，平移、缩放和普通画面刷新复用同一张图。
- 镊子采用下方长柄与横向弯头，从下往上夹住贴纸，贴稳后向下松开。
- 镊子提起时播放约 0.18 秒的纸张撕拉音；贴稳后播放按压声与轻柔上行奖励音，约 0.23 秒。手动拖放和 AUTO PLAY 均使用这两种音效。横向浏览托盘不会触发撕拉声。
- 音效由浏览器本地合成，通过独立音效通道播放，不受音乐开关影响；页面隐藏时暂停。

新增参考：`My Sticker Room - Decor Game-360 X 640-2026-10-08-fc78980db834d08d3cfd5da036b7ec92.mp4` 和用户提供的弯头镊子截图。音效按视频操作时刻与音轨瞬态调整节奏，仍为本地合成声音。

## 玩法与参考

参考用户提供的 `My Sticker Room - Decor Game-720 X 1280-2026-10-08-4e67cc4aeeaea9f417622d57339a481f.mp4`（720 × 1280，约 60 秒）。参考视频以手绘等距商店为场景，从底部取贴纸，逐步放入商品、柜台和人物，并缩放查看细节。

本样本制作一间可完整布置的原创 Juicy Journey 杂货店，共 36 张贴纸；房间、家具、商品使用统一的等距坐标绘制，人物使用独立透明贴纸。它是参考玩法的品牌改编，人物与商品布局使用新素材，并非原视频的逐帧素材拷贝。

贴纸包含：空调、窗户、三类货架、冷柜、收银台、梯子、招牌、海报、绿植、购物车、地垫、收银机、面包、17 组商品，以及 Sera、两位朋友和小狗。

这是安静的装饰玩法，错误操作返回贴纸并给出提示，无计时淘汰或强制结算。人物是可摆放的静态贴纸。
