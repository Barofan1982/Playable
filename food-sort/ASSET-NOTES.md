# 资源说明

- 食物：复用本项目 `stack-merge/source/prepared/food-4,5,6,7,8,9.webp` 的有体积食物图（牛排、沙拉、薯条、虾串、汉堡、披萨）。同一图在餐盘、备餐格和订单中保持比例，不使用平面图标替换。
- 角色：复用本地游戏内半身 prepared 图 `seagull/zuri/oli/chloe`。`sera` 仅用于成功奖励弹层，不进入客人列表。
- 深色盘子、餐厅背景、窗口、柜台、备餐槽和粒子由 Canvas 绘制，没有复制参考视频中的品牌背景。
- 音效使用短促 Web Audio 正弦音，没有外部配乐文件、BGM 数据或音乐开关。
- 所有资源均内嵌在 `index.html`，支持离线预览。
