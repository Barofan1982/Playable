# Food Sort · 食材分拣订单

独立单文件 HTML，三关连续分拣餐盘、组合双物料订单。九个餐盘只允许取出最上层物料，下面的物料会在取走后露出；未配对物料占用四格备餐区，满格仍未组成当前订单即失败。

- 客人使用游戏内半身海鸥、Zuri、Oli、Chloe；Sera 只出现在成功奖励层。
- 点按餐盘即可拾取，参考订单使用两张食物图，无配方英文说明。
- AUTO PLAY 使用相同顶层拾取和四格容量规则，可暂停、继续；手动点按会接管操作。
- 三关合计 32 个订单、64 次拾取，自动演示约 49 秒结束。成功或失败保留结果，由 RETRY 手动重试。
- 竖屏大盘面；横屏时完整居中，不重排或裁切场景。
- 无背景音乐及音乐开关；短促拾取/交单音效由用户操作解锁，页面隐藏时暂停。

维护源码保存在 `source/`，运行 `node source/build.cjs` 生成自包含 `index.html`。美术引用只在构建时读取，成品无需网络或其他资源。
