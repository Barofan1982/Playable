# Juicy Journey — Juice Bar Rush

根据本次 43 秒经营跑动视频制作的 HTML 试玩。

直接用浏览器打开 `index.html`，无需联网。图片、模型和脚本均包含在这一份文件中。

## Sera 与搬运更新（2026-10-03）

主角改为 Sera，领取的现金持续背在身上，移动时摆动；到升级地块停下后逐叠投入。饮品和现金可同时携带。

移动主角采用同一套本地 Sera 3D 模型：橙红侧辫、绿色眼睛、雀斑、青色蝴蝶结、黄色荷叶上衣、青色花裙和棕色凉鞋；转身、摆臂和步行保留。顾客和员工继续使用不同外观。

## 操作

- 在游戏画面中按住并拖动，控制角色移动；松手停止。电脑也可以用方向键或 WASD。
- 靠近机器前的取货区，自动把饮品堆高搬走。
- 站在柜台后方，自动服务排队顾客；每单消耗 3 份饮品，产生 10 元现金。
- 走进柜台旁的收款区，领取现金。
- 站在 60 元地块上投入现金，升级榨汁机和搬运容量。
- 再站到 180 元地块上，打开第二个柜台。部分投入会保留，离开地块后可继续投入。
- 达成目标后显示 Good Job!，可选择继续经营或重新开始。

左上角使用 Juicy Journey 商标。支持手机竖屏和浏览器横屏。

## 试玩范围

已实现移动、取货、搬运、服务、收款、升级、顾客排队和不耐烦反馈。角色、机器、车辆和场景使用程序化 3D 造型；本版本用于验证操作和画面方向，尚未逐件还原原视频的模型细节。

## 广告跳转

默认结尾按钮为重新开始。接入广告时，可通过全局 `clickTag` / `clickTAG` 或 URL 的 `clickTag` 参数配置跳转地址。

## 自动试玩（2026-10-09）

点击 AUTO PLAY 后 Sera 自动走到取货区、柜台、收款区和建设地块，实际搬运饮品与现金。每单仍需 3 份饮品，现金先收取再随身搬运，抵达地块后投入 60 / 180 元完成两次建设。

再次点击可暂停，RESUME 从当前位置继续。手动拖动或按移动键接管操作；RETRY 随时重新开局并停止自动演示。成功或失败后停止，保留结果，等待手动重试。支持手机横竖屏，横屏侧栏提供大按钮。

已检查触屏开始、暂停继续、重试、手动接管、结束保持及四种屏幕尺寸。`autoplay-checks.json` 为本地检查记录。

## 步行动作修正（2026-10-03）

Sera 的肩、肘、手掌与髋、膝、脚踝联动，左右脚轮流抬起与落地，双臂反向摆动；背货时保留摆臂。花裙分片摆动，侧辫随步伐摆动，上身轻微前倾。步伐按实际移动距离推进，停止后平滑回到站姿，重试重置动作。动作由本地几何体实时计算，没有增加外部素材。

`walking-checks.json` 记录实际渲染关节的四方向移动、载货迈步、摆臂、停步与重试检查；连续截图存于 walking-preview。

## 2026-10-10 载入与独立试玩更新

图片使用压缩后的内嵌 WebP。音乐数据放在玩法代码后，点击音乐按钮才解码；手动操作音效独立于音乐开关。HTML 无需外部图片、脚本或音乐文件即可运行。试玩界面没有返回列表按钮；合集卡片在新窗口打开本样本。
