# Juicy Journey · 货架三件归类

拖动货架上的商品，每格放齐三个相同商品即可清空。整理全部 16 组，在时间和步数耗尽前完成。

## 操作与规则

Drag goods into a shelf · 3 identical goods clear it

按住一个商品拖到有空位的货架，也可先点商品再点目标货架；只有三个完全相同的商品放在同一个格中才消除。每次有效移动消耗一步，放满的格子不接受新商品。

- 成功：16 组商品全部整理完成。
- 失败：时间或移动步数耗尽。
- 本轮限时：100 秒，90 个有效操作步数。
- AUTO PLAY 使用与手动操作相同的规则，可随时暂停；手动操作会暂停自动演示。
- 成功或失败直接显示简短提示；画面保留到手动 RETRY，不跳转其他试玩。结尾动画最长 0.7 秒。
- 音乐默认关闭，点击 ♪ 开启，重试保留声音设置。
