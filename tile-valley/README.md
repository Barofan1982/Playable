# 山谷水果落牌

参考视频5：`Tile Explorer_ Tiles Clear!-720 X 1280-2026-10-12-b50e289eeaa09beed1097652e364bf7b.mp4`，30.12秒。独立可离线运行的单页HTML试玩。

连续参考帧显示，山谷玩法是从上方落入水果牌；没有底部收纳槽。点击金框内一列，当前牌落在该列最上方的现存牌上；三个相同图案横向或纵向连续即消除。消除后的其他牌保持原格位，不压实整列。两岸台阶堆牌、内岸悬空牌与参考视频初盘一致：9列、12行容积，51张初始牌。新牌堆到顶会失败，清空所有水果牌获胜。预生成78步合法落牌序列，完整关卡可解。

底部60px控制栏、48px实际按钮：AUTO PLAY开始自动演示，PAUSE暂停，CONTINUE继续，RETRY从初盘重试。自动演示调用与手动相同的入列和横竖三同消除规则。页面或MRAID广告隐藏时动画、自动操作和操作音效冻结；没有背景音乐或音乐开关。竖屏完整显示，横屏居中，画面不裁切。

## 验证接口

浏览器提供`window.__qa`（亦可用`window.__playable`）：`state()`、`startAuto()`、`reset()`、`tap(col)`、`solve()`、`step()`、`fail()`、`pause()`。`solve()`依次调用真实规则完成初始关卡，`fail()`重复执行落牌直到一列满，不直接写入終局。`state()`返回固定格位网格、当前水果、可落列、剩余牌、操作数及当前阶段。
