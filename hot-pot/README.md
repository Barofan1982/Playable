# Juicy Journey · Hot Pot

更新：2026-10-12。单文件离线火锅配餐试玩。

## 玩法

5 位半身顾客依次点单，海鸥 → Zuri → Oli → Chloe → 海鸥；Sera 不作为订单顾客。

按订单图标点击底部食材，放入容量 8 份的网篮；点击锅/网篮开始烹煮。4.8 秒后绿圈提示熟透，点击提篮，再点黄酱或红酱，点击顾客订单提交。重复食材显示数量。图标勾选表示篮中已有足够份数。

提篮过早会夹生；煮超过 10.5 秒会过火。配料、数量、酱料、熟度任一不符会失去一颗心，同一订单可重做。累计 3 次失误失败，完成 5 单成功。无隐藏的总倒计时，成功/失败保留场景，只有 RETRY 重玩。

底部 AUTO PLAY 使用相同的加料、烹煮、提篮、加酱和提交规则，可暂停继续，手动操作接管。自动正常路线约 52 秒。场景、贴图及短操作音效全部内嵌，无 BGM、音乐开关、返回列表按钮或外部加载。

手机完整竖屏构图，横屏浏览器居中留两侧空间。控制按钮各至少 48px 高。
