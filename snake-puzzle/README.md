# Snake Puzzle · 贪吃蛇重力解谜

独立样本：`snake-puzzle/index.html`。打开后直接玩，共 8 关：前七关为短关卡，第八关为 121 苹果高难地图。

## 操作

- 在画面上向上、下、左、右滑动，或点击方向按钮。电脑也可用方向键 / WASD。
- 吃一个苹果，身体增加一格。身体跟随头部移动，不能穿过砖块或自身；原尾部在不吃苹果的那一步可以让开。
- 只要身体有一格位于砖块上方，蛇就能保持支撑；整条蛇失去支撑时一起下落。需要利用身体搭桥、绕弯。
- 吃完本关所有苹果并让头部到达旋涡才成功。坠落出界或碰到尖刺会失败。
- UNDO 撤销一步，包含身体位置和吃掉的苹果。RETRY 重置当前关卡。八个数字可直接选关。
- 第八关在手机上默认使用放大视角，每格约 34–44 像素，镜头跟随蛇头。− / + 调整缩放，MAP 查看全景，PLAY 返回放大的游戏视角。
- 右下角小地图显示剩余苹果、蛇身、出口和当前可见区域。拖动小地图可查看远处，下一次移动会恢复跟随；自动试玩时拖动小地图会先暂停，不移动蛇或修改苹果状态。
- 第八关压缩顶部商标、标题和计数的占用，保留 48 像素高的方向键与自动按钮。横屏使用右侧操作区，计数与操作区分开。

## 自动试玩与结尾

AUTO PLAY 根据同样的移动、增长、碰撞和重力规则完成关卡。初始地图使用已验算的路线；玩家处于已验算路线上的位置时，继续该位置的后续步骤，其他位置从实际盘面重新寻路。超过搜索预算仍未找到路线时停止并提示撤销或重试，不宣称该状态必然无解。

再次点击暂停，保留当前动画；继续后沿原进度运行。人工滑动或方向按钮接管，重试取消之前的自动操作。

手动通关点击 NEXT 换关；自动试玩在简短成功提示后连续换关，最后一关停留在完成画面。失败后等待人工撤销或重试，不自动重置。

## 画面、声音与体积

蓝天、光束、云朵、蛇、苹果、砖块和出口使用 Canvas 绘制。第八关使用深蓝背景、木质弯折平台和棕色 / 奶油色条纹蛇。眼睛、紫色嘴部、身体转弯、连续下落、吃苹果粒子和成功提示均可动。

配乐使用现有用户提供的 Ever So Blue - Onthou，前 30 秒，MP3 128 kbps，默认关闭并循环。音乐按钮只控制配乐；操作、吃苹果、成功、失败的音效独立，在用户首次操作后有效。页面隐藏或广告不可见时暂停声音。

单文件 HTML 内嵌 logo、音乐和运行代码，无额外运行素材，体积小于 5 MB。ZIP 仅保留本地归档，合集没有下载按钮。
