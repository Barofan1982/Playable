# Juicy Journey · 饮品发射合并

参考 `Tasty Travels_ Merge Game-720 X 1280-2026-10-02-53c1c1a2f67b7aaad7e7a9d6928f5b6e.mp4`，720 × 1280，约 59.35 秒。

直接打开 `index.html` 即可离线试玩，饮品素材、商标和脚本均内嵌。此前六个样本保持独立。

## 操作与规则

- 开局为 42 杯饮品组成的紧凑错列棋盘，横纵间距压紧，保留底部发射区域；初始静止，发射或碰撞后才会触发局部吸附。
- 在画面内左右拖动选择发射位置，松手向上发射；白线显示当前发射通道。
- 相同级别的饮品恢复收紧前的吸附范围，并扩大 30%：以原杯身半径之和为基准，乘 1.3。飞行、被碰撞推动的杯子和刚合成的产物进入范围后，会相互施加磁吸力，达到接触后合成；响应参数约为 0.12 秒，实际靠拢时间随来杯速度和碰撞变化。两杯在吸附过程中保留速度、相互传递推力。产物从接收杯当时的位置生成，继承两杯的合计动量，沿原推送方向继续滑行，逐渐减速，并能推动前方饮品、继续吸附连锁。静止盘面只在局部受力后移动，碰撞会阻挡磁吸路径。不同级别仅碰撞、挤压，不会合成或消失。
- 底部显示十级配方链，右上角 NEXT 显示下一杯。普通发射杯来自低级饮品洗牌队列。
- 普通低级合成只保留闪光，不增加金币。合成到绿色高脚杯（配方第 6 款）及后续高级饮品时，才有金色硬币飞向左上角；本试玩的订单奖励也使用该动画；硬币到达后计数增加，金币面板轻微弹动。
- 合成最终黄金水果壶后交付订单，奖励 600 金币。首个订单后切换为蓝白遮阳棚和白色桌面，桌上的剩余饮品继续保留。
- 完成一个订单显示 Good Job!，保留完成画面，不弹出结算或自动重试。KEEP MERGING 可以继续经营，RETRY 手动重开。
- 稳定堆积的饮品越过虚线会提示 Table Full，点击 TRY AGAIN 重试。
- HINT 只标出建议发射通道；不会替玩家合成。
- AUTO PLAY 按同一套发射、碰撞和合并规则演示；再次点击可停止，也可通过手动拖动接管。
- 电脑也支持左右方向键选位、空格或 Enter 发射；声音默认关闭。

## 画面与还原范围

海滩、椰树、草棚、木框玻璃桌、订单单据、预览杯和配方链均重新绘制。饮品使用根据视频风格新生成的透明 3D 风格素材；页面运行按杯身底部校准的圆形碰撞、局部同级磁吸的双向作用力、合成时按两杯质量加权继承速度、碰撞传力与摩擦减速，采用固定视角 2.5D 绘制，没有使用原视频的 3D 模型。

所有饮品按可见高度统一校准，低级发射杯的高度差控制在约 26% 内；待发与已发饮品使用同一套尺寸。飞行时以连续的透视比例与位置插值缩小，发射杯没有合成弹跳缩放，较大的水果壶仍保留级别差异。

保留了由底部向上发射、同级接触合成、饮品体积递增、订单奖励和第二张白色桌面的表现。金币触发参考原片约 5 秒开始的高级饮品连锁；奖励金额和订单奖励是试玩参数，未当作原片内部数值规则。初始摆放、物理参数和出杯队列是本试玩实现；视频末尾的原品牌人物广告画面未作为结尾底图使用。

## 验证

- 390 × 844 触控与 1280 × 720 鼠标：实际选位、松手发射、碰撞和合并通过。
- 320 × 568 小竖屏与 667 × 375 小横屏：棋盘、NEXT、提示、自动演示与重试按钮完整显示，无页面溢出。
- 相同级别产生一个下一级；不同级别不合并，重试和拖动取消不会留下额外发射。
- 检查紧凑开局饮品互不重叠、未触发的同类杯保持静止、磁吸范围等于收紧前基准的 1.3 倍、60 单位偏离可平滑吸附而 72 单位偏离不吸附、合成后可继续磁吸连锁、每次合成必须达到接触阈值，并从接收杯当前的位置生成、继承运动、第一发仅推动附近饮品、发射前后尺寸一致和沿途连续缩小；低级合成不发金币、高级合成的金币飞行方向、到达后的计数与重试清理均通过。
- 新增惯性检查：吸附过程中接收杯受到推力；斜向合成后的杯子继续向右上移动，0.25 秒内约向右滑行 9、向上滑行 27 个棋盘单位，速度逐渐下降；不同级别的前方杯子被继续推动约 20 个棋盘单位。检查了合成瞬间的动量继承。
- 检查了每次合并的级别与物料守恒，以及最终水果壶交付、600 金币奖励、白色桌面切换、完成后的静止画面和手动继续。
- 越线失败与 TRY AGAIN 已验证；自动演示使用同一物理规则完成订单。物理检查包含加速推进模拟，不承诺每局相同完成时长。
- 未发现脚本异常；HTML 可离线加载，合集入口可正常打开。
