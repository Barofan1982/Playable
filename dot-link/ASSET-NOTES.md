# 素材说明

- 游戏名称及商标：Juicy Journey；商标使用合集既有压缩素材。
- 盘面、点、自由曲线、反馈及碎纸彩粒：Canvas 与 CSS 绘制，无外链素材。
- 参考视频：用户提供的 Collect Em All! Clear the Dots 视频，只用于分析操作机制。视频画面、人物和音频没有嵌入成品。
- 点位：六个独立布局；每关参考解经过碰撞几何校验，自动试玩使用同一套规则。
- 六关点位和自动参考路线向内收，外围保留完整可绕行空间；第一关自动示范采用直线和直角折线，手动仍可自由画线。
- 音效：Web Audio 合成轻短玻璃拨音、连接提示、完成提示和碰撞提示，独立于配乐开关。划线拨音使用正弦波及短暂音量包络，不使用摩擦噪声。
- 配乐：用户提供的 Ever So Blue - Onthou 前 30 秒，MP3 128 kbps，沿用合集配置。
- HTML 内嵌所有运行所需资源，可离线使用。广告正式投放所需的商店地址与渠道 SDK 对接可另行配置。
