# Juicy Journey · 同色双点连线

参考：用户提供的 Collect Em All! Clear the Dots 视频。玩法取自视频中的自由画线挑战；六个关卡重新设计在同一个 HTML 中。

## 开始试玩

双击 `index.html`。支持手机触屏和电脑鼠标，离线可玩；不需要另行加载图片、脚本或音乐。

- 从一个彩色点出发，按住拖动，自由画到同色的另一个点。
- 线条不能碰到其他颜色的点，也不能穿过已经连接的线。
- 连接全部同色点对即可过关，不要求填满盘面，没有倒计时。
- 松开尚未完成的线会撤回本次笔画，不消耗机会。
- 碰撞会消耗一次机会，三次碰撞后显示失败；按 RETRY 重试当前关。
- ↶ 撤销上一次完整连接，也可以从已连接的点重新画该颜色。
- ✧ 显示一条短暂参考路线；若被现有线挡住，会提示先撤销调整。

## 六个关卡

| 关卡 | 名称 | 点对数量 |
| --- | --- | ---: |
| 1 | First connection | 3 |
| 2 | Around the corner | 4 |
| 3 | The inside route | 4 |
| 4 | Make some room | 5 |
| 5 | Take the long way | 5 |
| 6 | Tangled together | 6 |

上方的小数字页签可以直接选关。手动通关后按 NEXT → 继续；最后一关保留画面，直到手动重试或选关。没有跳转到其他试玩。

界面已精简为画布、关卡页签和必要的操作按钮，移除了侧边介绍与重复说明。竖屏时画布接近屏幕宽度；窄横屏时控件放到侧边，画布按可用高度放大。字母圆点半径由 17 增至 30，字母由 14 增至 23；起笔和终点吸附的判定范围同步扩大。已完成的点仍保留字母，方便对应。

## 自动试玩

AUTO PLAY 按实际画线和碰撞规则，连续演示当前关及之后的关卡。每条线逐步绘制，关卡之间只停留约 1.2 秒。可以 PAUSE / RESUME，RETRY 会停止自动操作并清空当前关。启动时会清空已有笔画，以免玩家画出的路线挡住参考解。

第一关的自动示范使用一条笔直的对角线和两条清晰的直角折线。六关的圆点和参考路线均向内收，给盘面四周留出连续空白，方便手动画线绕外圈；圆点大小和手动自由画线方式保持不变。

## 声音

操作音效由手动操作启用，独立于音乐开关。右上角音乐按钮只控制配乐。

划线音效使用轻短清脆的玻璃拨音，移除了原有擦擦噪声。持续划线时约每 0.24 秒、且移动一定距离才提示一次；细小抖动不会连续触发。

配乐沿用用户提供的 Ever So Blue - Onthou，前 30 秒，MP3 128 kbps，循环播放，默认关闭；页面隐藏时暂停。

- 正式 ZIP：合集 `下载包/dot-link.zip`，与当前 HTML 对齐，低于 5 MB。

## 源码

`source/template.html`、`source/game.js`、`source/rules.js` 是页面和交互源码。`source/levels.json` 保存六关点位及自动示范路线。`source/build.cjs` 构建独立 HTML；`source/check.cjs` 使用隔离的浏览器检查。参考视频抽帧仅用于分析，不进入交付 HTML 或 ZIP。
