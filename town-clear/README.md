# Town Clear · 整理小镇

根据用户确认的第一组近景构图制作。点击可见物件，按语义类别收集；同一类别允许不同造型。目标是把99件物品全部归档，使小镇只剩街道、人行道、地基和空地。

## 独立物件

- 99个独立WebP文件、99个唯一编号、99份位置/前后层级/点击轮廓/收集状态，内嵌到单文件HTML。
- 素材以批准的概念图风格生成后逐格拆分，清理分离的裁切残片与透明空白。不是在完整概念图上盖点击框。
- 同类外观来自48款基础原画及少量色调变化；每件最终物品均有独立文件。同类可以复用造型，不表示99张完全不同的原画。
- 房屋没有附带植物、人物没有手持可收集物；植物、动物、家具、车辆均单独存在。
- 固定地面由程序绘制，图中不存在收不走的树、人或车辆。全部清空时不再绘制任何物件。

## 玩法

- 20类，每类3–7件，共99件。居民6、猫4、狗5、鸟3、小汽车5、自行车4、踏板车3、民居3、商铺4、树木7、灌木6、盆栽7、椅子7、桌子5、长椅4、沙发3、纸箱7、垃圾桶5、轮胎5、路锥6。
- 顶部同时显示三个收纳箱，展示当前类别订单，完成后轮换。订单数量取该类真实库存，不使用每类33件。
- 当前订单需要的物件飞向对应箱口，入箱时闪光并横向伸展回弹，再计数；其他物件进入7格暂存栏。后续订单出现时，暂存栏对应物品自动归档。
- 按实际透明轮廓判断，优先命中最上层物品；不穿透上层物件。房子和杂物移走后露出下层内容与地基。
- 暂存栏允许存满7个物件；满栏时仍可收取当前订单物件，再点第8个非目标物件才失败，Retry重新开始。没有倒计时。
- 成功要求盘面为空、暂存栏为空且99件全部归档，保持最终空场；无CTA。
- Auto Play根据当前真实可见物件执行同一收集规则，支持暂停与手动接管。Space切换自动演示，Backspace重置。手机直接轻点物件。

## 交付

英文竖屏界面，横屏完整居中。没有BGM或音乐开关；交互音效在用户操作后启用，后台暂停。

本地源码、独立物件和检查资料在source目录；本地ZIP在合集下载包/town-clear.zip。HTML内嵌全部资源，可单文件离线运行，约1.2MB，小于5MB。

检查覆盖：99个独立编号、20类库存、真实触屏收集、完整清空与20单交付、满7格继续收目标、第8个非目标失败、箱体收件反馈、重试、小手机及横屏完整显示。

## 2026-11-12 摆放修正

车辆沿街道排列，建筑落在街道两侧的地基上，家具、植物和杂物分布在店前与路边。缩小过大的家具，调整车辆与人物比例，取消物件随机倾斜。前后遮挡分为建筑最底层、车辆倒数第二层、其他物件前景层；每层内部按接地点深度绘制，检查99件物品的占地间隔与边界，屋顶完整显示。保留近景和层次，避免无规则堆叠。

## 建筑底层与地基对齐

房屋和商铺统一在最底层；汽车、自行车和踏板车在倒数第二层；人物、动物、植物、家具及杂物在前景。点击命中使用同一遮挡顺序，自动演示先清前景，再清车辆和建筑。小物件的落点避开建筑后方墙面区域。

7处地基分别使用对应房屋素材的两条底部墙线斜率与折角，按实际显示宽高映射并略微外扩。红顶、蓝顶民居和三款商铺各自对齐，不使用统一朝向的菱形；移走房屋后保留同一地基。
