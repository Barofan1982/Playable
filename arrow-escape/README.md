# Juicy Journey · 彩色箭头脱困

两关缠绕解谜：第一关保持 28 条不规则路线，通关后解锁 200 箭头地狱关。密集线路相互嵌套，可放大到 4 倍并拖动、双指缩放；三次碰撞或超时失败。

## 操作与规则

Trace each arrowhead · clear its route · avoid 3 collisions

点击弯曲线路，系统沿箭头朝向检查直到棋盘边缘；前方有其他线路会碰撞并消耗一次机会，畅通则整条线路退出。

- 成功：先完成 28 箭头第一关，再解开 200 箭头地狱关。
- 失败：三次碰撞或时间耗尽。
- 第一关：28 条箭头、100 秒；通关后点击 HELL MODE 进入第二关。
- 第二关：200 条箭头、48×68 满盘，共 3,264 个格点；限时 600 秒，三次碰撞失败。
- 缩放：点击 + / −，滚轮或双指缩放至 4 倍；按住盘面拖动，FIT BOARD 恢复总览。拖动和双指缩放不选中箭头。
- 两关各有独立计时、进度与碰撞次数；RETRY 重试当前关。
- AUTO PLAY 使用与手动操作相同的规则，可随时暂停；手动操作会暂停自动演示。
- 第一关完成后保留通关提示，手动点击 HELL MODE 才进入第二关；若第一关使用 AUTO PLAY，进入第二关后自动继续。第二关胜负画面保持到手动重试，结尾动画最长 0.7 秒。
- 操作音效在首次用户操作后有效，页面隐藏时暂停。
