# Juicy Journey · 彩球机关灭火

消除绿色叶片积攒水球，充满后点击横杆释放一批水球。完成三轮降温救出 Sera；红色图块会助长火势。

## 操作与规则

GREEN charges water · tap the PIN at 8 · RED feeds fire

点击至少两个上下左右相邻的同色图块；孤立图块不能消除。石板、水位、火势或闸门随着实际操作变化。彩球灭火还需要手动点击充满后的横杆。

- 成功：释放三批水球并熄灭火焰。
- 失败：火势达到危险线、时间或步数耗尽。
- 本轮限时：55 秒，26 个有效操作步数。
- AUTO PLAY 使用与手动操作相同的规则，可随时暂停；手动操作会暂停自动演示。
- 成功或失败直接显示简短提示；画面保留到手动 RETRY，不跳转其他试玩。结尾动画最长 0.7 秒。
- 音乐默认关闭，点击 ♪ 开启，重试保留声音设置。
